## 3. Собрать финальные признаки

## 4. Сделать генератор фейковых ботов

📁 `src/generator.py`, `tests/test_generator.py`, `notebooks/04_generator.ipynb` (посмотреть на сгенерированных ботов глазами)

В реальных данных нет ответа «бот / не бот», значит, проверять детекторы придётся на своих ботах.

- [ ] Каких ботов делать? Те, что нашлись в данных: круглосуточное воспроизведение, зацикливание, вспышки повторов, циклические лайки. И те, что не нашлись: «экономный» бот на пороге, группа аккаунтов, накручивающая один трек.
- [ ] Насколько явным делать бота? Нужна сила: от грубого до едва заметного.
- [ ] Насколько бот может притворяться человеком? Нужна маскировка: паузы, разные треки, сон.
- [ ] Делать полностью фейковых или подмешивать накрутку в историю реальных людей? (Второе сложнее поймать и честнее.)
- [ ] Как проверить, что боты получились такими, как задумано? Тесты на pytest.
